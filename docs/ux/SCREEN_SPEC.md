# Screen specifications

1. Command Center - 7 KPI max, top opportunities, evidence readiness, offer coverage, mission issues, cash milestones.
2. Growth Pipeline - stages, gates, score, owner, next action.
3. Opportunity Room - score decomposition, blocking gates, requirements link, human Bid controls.
4. Reference Portfolio - service/country/year/proof status.
5. Reference Detail - evidence ledger, reusable/verified state, blockers, experts.
6. Experts - skills, sectors, countries, availability signal, references.
7. Knowledge Search - role-filtered, source-backed search with abstention.
8. Offer Workspace - exact requirement matrix, mandatory flag, evidence, owner, due date, status.
9. Missions - authorized mission cards only.
10. Mission Workspace - PBC, documents, prompt-injection fixture, review points, draft analysis.
11. Actions - cross-module owners/due dates/status.
12. Cash - synthetic billing milestones only; not accounting production.
13. Security - audit/denied events.
14. Assistant - secondary contextual surface; live/fallback mode.
15. Next Step - 90-day pilot sequence.
16. Admin Health - mode/version/dataset health.

Every P0 screen must have loading/error/empty/forbidden states added during Hermes implementation hardening.

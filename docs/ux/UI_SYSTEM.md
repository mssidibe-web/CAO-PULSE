# UI system

Intent: “executive operating cockpit”, not chatbot. Navy/ink base, teal accent, semantic green/amber/red; accessible text+color status.

Principles:
- top 3-7 decisions visible, not dozens of vanity KPIs
- evidence/source proximity: source shown beside claim
- progressive disclosure: summary -> drilldown -> evidence ledger
- blockers visually separate from scores
- next action + owner + due date on operational objects
- AI badge shows live/fallback mode when surfaced
- all synthetic data clearly labelled

Target viewport: 1366x768 and 1440x900. Mobile is not a P0 presentation target.

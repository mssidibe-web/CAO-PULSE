# Research method - auditable design

## Question
Which product patterns, model architecture and engineering controls are appropriate for a synthetic C.A.O demonstration that supports bid management, evidence reuse, management steering and engagement assistance?

## Method
1. Start from the signed/approved C.A.O cahier des charges.
2. Use primary/official sources for Hermes behavior, model capabilities and benchmark products.
3. Classify every claim as vendor claim, verified platform behavior, project hypothesis or design decision.
4. Never infer comparative superiority from separate vendor metrics.
5. Use benchmark products only to identify patterns, not to copy proprietary workflows/UI.
6. Keep runtime AI provider-neutral; evaluate candidate models on a fixed C.A.O test set.
7. Preserve raw model outputs and metadata for reproducibility.
8. Tie requirements to code/test evidence via `REQUIREMENTS_TRACEABILITY.csv`.

## Search date
30 September 2026. Time-sensitive items must be re-checked before implementation or a production pilot.

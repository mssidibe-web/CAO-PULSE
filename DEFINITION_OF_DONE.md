# Definition of Done - Founder-ready demo

All must be true:
- `npm run identity:check` passes on the final repository and target machine.
- `PROJECT_IDENTITY.json` matches the package, client, canonical source hash and repository identity.
- Command Center, Growth, References, Offers, Missions, Security, Assistant and Next Step routes work.
- Synthetic dataset is stable, coherent and resettable.
- Offline founder scenario completes end-to-end.
- Server-side permission tests and blocking gates pass.
- Proof readiness cannot be achieved without reusable evidence.
- Requirement coverage is calculated from underlying evidence links.
- AI outputs either cite supplied sources or explicitly abstain/label inference.
- No automated audit opinion, independence decision, signature, email, portal submission or client-facing external action.
- Live provider is optional and kill-switchable.
- Model selection has a dated evaluation artifact; no unsupported “best model” claim.
- 1366x768 and 1440x900 visual smoke passes.
- `audit-pack`, traceability verification, tests and preflight succeed.
- `docs/PACK_VALIDATION_REPORT.md` records checks, limitations and known gaps.
